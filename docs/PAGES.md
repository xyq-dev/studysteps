# 页面清单（STP 004 最小可操作范围）

S03–S18、P01–P04、A01–A06 的完整入口仍以 `PROJECT_PLAN.md` 编号连续保留。本阶段只固定 S01、S02、P05、P06 的最小动作。高保真稿：**未完成**。

## S01 身份与适龄引导

- 入口：Web 根路径；家长登录。
- 字段：中国大陆手机号、6 位验证码、设备安装标识（客户端生成，非凭证）。
- 主操作：发送验证码 → 兑换 GuardianSession。
- 年龄：未确认只看静态说明；`AGE_18_PLUS` 静态说明并拒绝建档。
- 状态：加载、校验错误、限频、登录失效、测试环境提示。
- 返回：已登录且无档案 → S02；已有档案 → P05。

## S02 学习档案设置

- 入口：S01 成功后或 P05「开通档案」。
- 字段：昵称、内置头像、年龄段、时区（默认 Asia/Shanghai）、测试政策确认勾选。教育资料不在建档时写入，须走后续 PATCH。
- 主操作：接受当前测试政策并建档。
- 必须展示：监护人声明原文；测试政策标记；学习功能尚未开放。
- 状态：缺少同意、年龄不支持、版本冲突、请求失败。
- 返回：成功到 P05。教育快照保持全空；年级配齐走后续 PATCH。正式学习记录仍属后续任务。

## P05 档案与设备

- 入口：家长会话。
- 主操作：列表、查看、进入学生模式、创建／展示配对、撤销配对、撤销学生设备、登出。
- 字段：档案摘要、设备标签、最近活动、过期／撤销状态；配对首次展示 `pairingId` 与短码。
- 状态：`ONBOARDING` / `RESTRICTED`、需要二次验证、无权限、未实现入口（导出／删除）显示真实不可用。
- 返回：学生模式进入裁剪后的学生视图；切回家长必须走 S01 二次验证，不能只靠前端开关。

## P06 授权与数据

- 入口：指定档案。
- 主操作：阅读当前测试政策、查看历史、授予、撤回。
- 撤回：consentId + 原因；不提交学生 version。
- 导出／删除：标明后续未实现，禁止假成功。
- 返回：P05。

## S07 计划模板库

- 入口：P05／学生视图「打开模板库」。自定义年级也可进入。
- 主操作：浏览已发布模板；有 `catalogEntryKey` 时展示推荐；无合法映射禁止导入。
- 状态：可浏览；无映射禁止导入；合法映射可预览／确认导入（STP 006 第一批）。S06 空白创建已开放最小闭环。
- 高保真：**未完成**（STP 002 优先页不含 S07）。

## S06 自己添加计划

- 入口：P05／S05／学生视图「自己添加」。
- 字段：任务名、科目、完成标准、重复方式。
- 主操作：预览 → 确认创建；监护人须勾选双方约定。取消不写库。
- 状态：保存中禁用确认；失败保留输入；成功后 S08／S05 展示服务端结果，刷新仍可查看。
- 自定义年级无模板映射时仍可手动创建。
- 高保真：**未完成**。
