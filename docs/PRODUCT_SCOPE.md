# 产品范围（STP 004 阶段固定稿）

来源：`docs/PROJECT_PLAN.md`、`docs/STP004_DESIGN.md`、`docs/CURSOR_STP004_IMPLEMENT.md`。  
本文件只固定本阶段可实现边界，不改写主方案结论，不宣称全量 M0 已冻结。

## 产品目标

StudySteps 是独立的家庭课后学习产品。P0 验证孩子能否更少依赖催促地完成自己参与制定的计划。学习时长只是辅助记录。

独立于 Yuwang／渔网杯：独立仓库、数据库、账号域和素材空间。

## 角色

| 角色 | 本阶段能力 | 禁止 |
| --- | --- | --- |
| 未认证访问者 | 申请登录验证码、阅读已发布测试告知元数据 | 建档、枚举账号或档案 |
| 主监护人 | 开通未成年人档案、声明监护关系、管理本档案设备／配对／同意 | 凭账号访问无关系档案；代平台核验法定关系 |
| 学生会话 | 只访问绑定的一个档案的安全裁剪视图 | 家庭列表、同意／设备管理、提权为家长 |
| 内容管理员／支持人员 | 不在本阶段实现 | 复用家长会话 |

## P0／P1／P2

P0 同时包含档案授权基础。本阶段只交付账号、档案、同意、会话、配对与撤销。计划、任务、计时、复盘、报告、导出／删除、模板与年级目录属于后续 STP。

P0 不包含照片、外部 AI、支付、题库、公开社区、陌生人私信、班级、直播或奖励商城。

## 本阶段成功口径

- 未确认年龄不持久化 `StudentProfile`。
- 未满 14 岁与 14–17 岁由监护人开通并接受**测试**政策；18 岁及以上拒绝正式建档。
- 每个对象请求检查具体档案的有效 `GuardianLink`。
- 撤销后旧会话与配对立即失败。
- 学习访问保持 `allowed=false`，阻塞原因 `ACADEMIC_CONFIGURATION_PENDING`。
